# Planejador Inteligente de Férias

Aplicação web para ajudar trabalhadores CLT a planejar melhor seus períodos de férias, considerando datas disponíveis, feriados, finais de semana e possíveis divisões de férias.

> Projeto em desenvolvimento.

## Tecnologias

- React
- TypeScript
- Vite
- Vitest

## Como executar

Clone o repositório:

```bash
git clone https://github.com/jessicamartns/ferias-inteligentes.git
```

Entre na pasta do projeto:

```bash
cd ferias-inteligentes
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

## Testes

Para executar os testes:

```bash
npm run test
```

Ou executar uma única vez:

```bash
npm run test:run
```
